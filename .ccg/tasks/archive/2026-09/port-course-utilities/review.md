## 发现与修复

| 级别 | 问题 | 修复与验证 |
| --- | --- | --- |
| Critical（已修复） | 可能对非幂等上报进行自动重试或在重启后重放；私有来源参数与账号边界需要隔离 | 上报请求禁用自动重试，次数/时长中断保留结果并结束为 partial；校验同账号来源快照与资源选择，仅发布公开 DTO |
| Warning（已修复） | 缺失章节 ID 容易被当成锁定章节，导致资源漏读 | 只有明确锁定标记才跳过；增加异常与真实锁定的成对回归 |
| Warning（已修复） | catalog purpose 的数组/对象输入可能造成服务端异常 | 严格校验并返回 400 |
| Warning（已修复） | 下载恢复依赖已过期的来源任务，进度或输出目录可能丢失 | 持久化独立选择配方、已完成结果、计数与目录；覆盖实际来源过期后的恢复 |
| Warning（已修复） | 资源目录大小未完整考虑 JSON 转义和后续结果，可能超过 Tauri 2 MiB 响应上限 | 按完整 ASCII 转义 JSON 计算容量并预留结果空间 |
| Warning（已修复） | 失败/取消后删除临时文件，但仍显示当前文件已保存字节 | 区分接收中与已发布文件；停止/失败清零当前下载进度，保留完成文件 |
| Warning（已修复） | 检查点失败可能继续执行、重复追加结果或保留被丢弃的在途字节 | 检查点异常停止任务推进；真实流式下载回归验证已发布结果保持一致 |
| Warning（已修复） | Windows 8.3 数据路径与服务实际返回路径不一致，导致结果相对路径转换失败 | 先拒绝链接祖先再规范化路径，使用同一目录；真实 Win32 短路径测试通过且未跳过 |
| Warning（已修复） | 移动端资源启动错误出现在列表上方，操作位置看不到反馈；终态详情可能尚未到达 | 错误提示放到启动按钮附近；仅在最终详情和 completed/partial 状态确认后开放后续操作 |
| Info | 下载、上报依赖平台实际响应 | 离线 fixture 验证接口解析与状态行为；平台统计可能延迟或合并请求，UI 区分成功提交与实际统计 |
