# 课程辅助功能迁移

将本地 `chaoxing_tool/` 中的学习次数、视频观看时长和课程资源下载迁移到现有 chaoxing-gui。保持当前登录、账号隔离、课程选择、设计语言、任务日志/进度、停止和重启恢复习惯。浏览器、Electron 与 Tauri 的请求路径必须一致可用。

- 学习次数：选择课程、配置次数和间隔，展示请求执行结果与平台可读统计，允许停止。
- 视频时长：列出可用视频并选择，配置目标时长，以可取消的播放上报推进，准确处理不足一分钟与超过视频长度的情况。
- 资源下载：读取课程章节中的视频、音频、文档等可下载资源，按需选择，流式下载、进度展示、失败反馈及安全命名，下载完成后能获得文件。
- 不引入上游 CLI 菜单/全局账号状态，不要求运行或安装本地参考仓库。
- 网络和账号全部使用 mock 验证，不使用真实账号刷取或下载。
- 工作区已有用户改动，保留并在其基础上接入功能。用户后续要求完成后推送 GitHub，提交本次功能代码；发布由 `publish-course-utilities` 跟踪，沿用产品代码与本地 CCG 归档分离的既有约定。

复杂度 L+；风险 high（新增 API、下载与桌面契约）。用户补充“无需调用双模型分析”，已停止两次分析进程，改为本地直接分析。实施按文件归属并行，完成后进行测试和审查。
