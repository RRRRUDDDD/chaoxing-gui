# 需求与边界

1. 在任务执行期间退出桌面应用，重新打开并登录同一账号后，继续原有选课与设置对应的未完成学习任务。恢复依赖持久化的任务信息，不能仅沿用已失效的内存任务 ID；不得重复启动同账号任务或重启已完成任务。
2. 课程页和进度页右上角 GitHub 图标均应在系统默认浏览器打开固定仓库地址，兼容 Tauri、Electron 与普通浏览器。
3. 无历史选择时课程列表默认全不选，保留规范要求的同账号显式选课交集；支持 Ctrl+A（兼容 Cmd+A），不拦截输入框内的文本全选。
4. 开始任务和更新日志时不抢夺焦点、不把整个页面滚动至日志区域。日志区域内跟随最新日志应尊重用户手动滚动。

## 约束

- 遵守现有前后端规范，恢复信息不持久化登录密码。
- 保持桌面关闭时后端进程清理行为；关闭应用期间不继续后台刷课。
- 隔离账号与异步请求，恢复失败要明确可见并保留重试或重新选课入口。
- 仅改动本任务所需文件，保留已有用户修改。
- 使用隔离测试数据，不操作真实账号或执行真实学习任务。
