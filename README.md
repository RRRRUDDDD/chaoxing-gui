# 超星学习通自动化工具

[![Build Windows Package](https://github.com/RRRRUDDDD/chaoxing-gui/actions/workflows/main.yml/badge.svg)](https://github.com/RRRRUDDDD/chaoxing-gui/actions/workflows/main.yml) [![Release](https://img.shields.io/github/v/release/RRRRUDDDD/chaoxing-gui)](https://github.com/RRRRUDDDD/chaoxing-gui/releases/latest)

用于超星学习通课程的自动化学习与资源管理工具，提供 Windows 桌面应用、浏览器界面和命令行入口。支持视频学习、题库配置、课程时长工具和资源下载，并可查看任务进度与日志。

[下载发行版](https://github.com/RRRRUDDDD/chaoxing-gui/releases/latest) · [报告问题](https://github.com/RRRRUDDDD/chaoxing-gui/issues) · [开发指南](DEVELOPMENT.md)

## 功能

| 功能 | 说明 |
| --- | --- |
| 自动学习 | 选择课程执行学习任务，支持视频倍速和章节并发设置 |
| 题库答题 | 接入 OCS 格式题库 JSON 或订阅链接，可设置答案覆盖率和是否自动提交 |
| 学习次数 | 设置每门课程的提交次数与间隔，查看提交结果和平台统计 |
| 视频时长 | 选择视频并设置新增时长，按实际时间运行，支持停止 |
| 阅读时长 | 选择支持计时的专题阅读任务，在独立浏览器窗口中运行并查看上报结果 |
| 资源下载 | 筛选下载视频、音频、文档等课程资源，查看进度并打开保存目录 |
| 任务管理 | 查看进度、日志和历史结果，返回选课页后可继续查看运行任务 |
| 外部通知 | 可配置 Windows 系统通知、Server酱、Qmsg酱、Bark 或 Telegram |

不同课程的页面、权限和任务要求可能不同，部分功能不适用于所有课程。程序显示的执行结果不等于平台最终认定的学习进度或成绩。

## 下载与安装

### Windows 桌面版（推荐）

1. 打开 [GitHub Releases](https://github.com/RRRRUDDDD/chaoxing-gui/releases/latest)。
2. 在该版本的 **Assets** 中下载 Windows x64 发行文件，而不是 `Source code` 源码压缩包。
3. 根据文件类型启动：

| 下载文件 | 使用方法 |
| --- | --- |
| 名称含 `setup` 的 `.exe` | 运行安装程序，完成后从开始菜单或桌面快捷方式启动 |
| Tauri 便携版 `.zip` | 完整解压到可写文件夹，再运行 `Start-Chaoxing.cmd` |
| 名称含 `python` 的 `.zip` | 独立 Python 版：完整解压后运行 `chaoxing-gui.exe`，控制台在默认浏览器中打开；数据保存在解压目录，与 Tauri 版不互通 |
| 旧版 `desktop-portable` 单文件 `.exe` | 按对应 Release 的说明直接运行；其功能和数据位置可能与新版不同 |

桌面发行包不要求另行安装 Python、Node.js 或 Rust。**Tauri 便携版不能在 ZIP 内直接运行，也不能只复制其中一个 EXE**，请保留解压后的全部文件。

当前 Tauri 桌面版需要 **Microsoft Edge WebView2 Runtime**。安装版在缺少运行时时会尝试联网安装；便携版若提示缺少运行时，请运行包内的 `Install-WebView2.cmd`。离线安装方法见 [桌面版指南](desktop/README.md#webview2-与离线安装)。

Release 页面同时提供 `SHA256SUMS.txt` 和各发行文件的 `.sha256` 校验值，下载后可核对文件完整性。

### 从源码运行

如果你希望使用尚未发布的更新，或需要浏览器界面、命令行模式，请按 [开发指南](DEVELOPMENT.md) 准备环境。普通用户直接下载桌面发行包即可，无需自行构建。

## 开始使用

### 1. 登录账号

输入超星学习通的手机号和密码。登录成功后，程序可记住账号并复用本机登录会话；会话过期时需要重新输入密码。

桌面和 Web 界面不会将密码写入本地存储，但本机保存的登录会话仍属于敏感信息，请勿与他人共享。

### 2. 选择课程

点击课程卡片勾选需要处理的课程，也可以搜索课程后使用“全选”。`Ctrl+A` / `Cmd+A` 可全选当前列表，在输入框中则保留文本全选行为。

**至少选择一门课程才能开始，不选择不会自动执行全部课程。** 保存的课程选择按账号区分。

### 3. 选择功能并配置

在右侧“执行功能”中选择要执行的任务：

- **自动学习**：设置播放倍速、并发章节等参数，再点击“开始学习”。
- **学习次数**：设置次数与间隔，再点击“开始提交次数”。
- **视频时长**：点击“读取视频列表”，勾选视频并设置新增分钟数，再点击“开始累计时长”。
- **阅读时长**：点击“读取阅读任务”，勾选专题阅读任务并设置新增分钟数。
- **资源下载**：点击“读取资源列表”，筛选、勾选资源，再点击“下载所选资源”。

视频倍速范围为 `1.0–2.0`。不熟悉其他参数时可以先保留默认值。

学习配置或课程选择变化后会显示“有未保存的更改”；恢复原值后提示消失。点击“保存当前配置”后，成功与失败会分别提示。保存期间继续修改的内容仍需再次保存；桌面关闭方式单独即时保存。较小桌面窗口中，右侧参数区可独立滚动，开始与保存操作保持可见。

### 4. 查看进度或停止

任务运行后，进度页会显示执行状态、日志和结果。点击“停止任务”可结束当前任务；返回选课页后，可通过“查看运行任务”继续查看进度。

同一账号同时只能执行一个任务。失败、跳过、仅保存但未提交的测验不会被当作全部完成，请结合日志检查结果。

自动学习结束后会只读复核平台总进度和任务卡片。课程详情区分“平台已确认完成”“平台仍有未完成任务”和“平台完成状态未确认”；缺少页面字段、统计更新中或读取失败时，保留已执行计数并显示部分完成，不自动重学或重交答案。课程工具的次数、时长统计不在此复核范围内。

章节测验提交成功后会尝试读取新增作答记录的成绩，并写入任务日志；记录无法关联、成绩尚未生成或详情无法解析时明确提示未知。提交成功不等于全部答对，也不自动重做；仅保存的测验不查询成绩。


日志、通知正文和任务错误详情会统一遮盖常见认证字段、URL 及运行时登记的凭证；异常保留类型和栈帧位置，不记录局部变量。此保护不清理历史文件，也不能保证任意自由文本或截图中没有个人信息，分享前仍需检查。

结果摘要与详细统计位于日志之前。日志保留最近 500 条，可按级别筛选、搜索关键词，并复制当前匹配结果。上滚会暂停跟随，也可关闭“自动跟随”；点击“回到最新”恢复。复制时会遮盖常见敏感字段，但分享前仍需自行检查；剪贴板不可用或被拒绝时会提供只读文本供手动复制。

## 题库与通知

### 配置题库

依次展开“高级配置 → 题库配置”，点击“展开编辑”，在页内宽屏编辑区粘贴 **OCS 题库 JSON 数组**或填写**订阅链接**。返回配置面板不会丢失输入，也不会自动保存或读取订阅；确认后点击“保存当前配置”。程序不内置固定题库，留空时不自动答题。

- 点击“OCS 题库配置”可查看格式说明：桌面端使用系统默认浏览器打开，网页版打开新标签页。
- 支持常见 OCS handler 表达式及第三项对象元数据（如 `ai/tags`），但不执行任意 JavaScript。个别配置无效时会记录位置并跳过，其他有效题库继续工作。
- 图片题扩展按 OCS dev 协议生成：普通题自动填入空扩展值；引用扩展字段的 POST 配置会按需上传受限图片数据。图片转换失败会回退到原始文本并记录诊断，不保证题库一定能找到答案。
- 默认仅保存答案、不自动提交；需要自动提交时，可调整“自动提交答题”和“最低覆盖率”。
- 覆盖率表示找到答案的比例，不代表答案正确率。题库返回的答案需要自行核对。
- 建议保持“校验题库 HTTPS 证书”开启。关闭会降低连接安全性，不应作为题库无响应时的常规处理办法。

### 配置通知

在“高级配置 → 外部通知”中选择通知服务，按界面填写对应地址或参数。不需要通知时保持“不使用通知”。含 Token 的通知地址属于敏感信息，请勿在截图或问题反馈中公开。

## 使用注意事项

### 阅读与平台统计

阅读时长功能需要本机安装 **Chrome 或 Edge**，运行时会打开独立阅读窗口，请保持该窗口打开。仅支持具有阅读计时功能且正文可滚动的专题阅读页面，普通课件和视频不属于此功能。

视频、阅读时长按实际时间执行，并非瞬间增加。阅读任务会滚动正文并展开后续章节；加载章节的等待时间不计入阅读进度，短时任务不保证遍历整本书。

平台统计可能延迟、合并请求或次日更新。**成功提交或已上报时长，不一定等于平台实际增加量，也不代表已经达标。** 请以平台最终显示为准。

### 下载与任务恢复

下载完成后，点击“打开下载目录”查看文件。资源保存在程序数据目录的 `downloads/<任务 ID>/` 下；同名文件会另存，文档优先保存平台提供的 PDF。

重新打开程序后，资源读取和下载任务可恢复，已确认保存的文件会保留。次数和时长任务在异常退出后会结束本次执行并保留记录，请先核对平台统计，再决定是否重新开始，避免重复累计。

### 关闭窗口

Tauri 桌面版默认询问“最小化 / 最小化到托盘 / 退出程序”。可以记住选择，也可以在“高级配置 → 关闭窗口时”修改。

最小化或收进托盘可继续运行任务；选择退出会中断正在运行的任务。托盘菜单可恢复窗口或退出程序。

## 数据与升级

当前 Tauri 桌面版使用以下目录，可复制路径到 Windows 文件资源管理器打开：

| 内容 | 位置 |
| --- | --- |
| 账号会话、配置、任务记录和下载文件 | `%APPDATA%\com.chaoxing.gui\data` |
| 桌面运行日志 | `%LOCALAPPDATA%\com.chaoxing.gui\logs` |

数据目录中也可能包含后端的 `chaoxing.log`。便携版同样使用当前 Windows 用户的 AppData，数据不会随便携文件夹移动；卸载 Tauri 应用后，AppData 数据仍会保留。

- **升级前先退出程序并备份数据目录。** 从旧版桌面程序迁移时，也请备份 `%APPDATA%\chaoxing-desktop`。
- 新版安装器不会直接覆盖旧版桌面程序目录，请选择不同的安装目录。首次运行新版前应关闭旧程序，以便导入已有数据。
- 新版任务记录格式与旧版不兼容，不要直接用旧版本覆盖新版数据。需要降级时，请使用升级前的完整备份。
- 不要上传或分享数据目录，其中可能包含登录会话、题库配置和通知密钥。

## 常见问题

### 登录失败或出现验证码怎么办？

先确认账号密码和网络连接正常。保存的会话失效时，重新输入密码登录。遇到验证码或平台风控提示，请在浏览器中手动完成验证后重试；不要依赖程序自动处理所有验证码，也不要持续高频重试。

### 题库没有返回答案怎么办？

检查 JSON 格式、订阅链接、题库服务状态，以及服务要求的认证信息，再查看任务日志中的具体错误。降低“最低覆盖率”不会修复网络问题或增加题库能找到的答案。

### 任务显示完成，平台进度却没有变化？

先检查结果中是否有失败或跳过项，再刷新平台页面并等待统计更新。部分阅读统计可能次日才更新；上报成功不代表平台已判定达标，不建议立即重复执行相同任务。

### 资源列表为空或下载失败？

确认账号有权访问对应课程和资源。课程内容变化、链接过期时，请重新读取资源列表；资源较多时可减少所选课程、分批下载。

### 程序无法启动或页面打不开？

- Tauri 桌面版：确认 WebView2 已安装，便携包已完整解压，程序文件没有被单独移动；按启动页面提示查看错误。
- 源码 Web 版：确认前后端终端仍在运行，访问 `http://localhost:3000`。默认前后端分别使用 `3000`、`5000` 端口；端口冲突时先确认占用程序，不要盲目结束未知进程。

仍无法解决时，请到 [Issues](https://github.com/RRRRUDDDD/chaoxing-gui/issues) 提供版本号、Windows 版本、复现步骤和脱敏后的日志或截图。不要提供密码、Cookie、Token 或完整个人数据目录。
